# Firebase Authentication & Database Demo (Flutter)

A Flutter application demonstrating Firebase integration with:

* Firebase Authentication
* Firebase Realtime Database
* Cloud Firestore
* CRUD Operations

---

## 🚀 Features

### 🔐 Authentication

* User Registration
* User Login
* User Logout
* Firebase Email/Password Authentication

### ☁️ Cloud Firestore

* Add Data
* Read Data
* Update Data
* Delete Data

### 📦 Realtime Database

* Store Realtime Data
* Fetch Realtime Data
* Update & Delete Records

## ⚙️ Firebase Setup

### 1. Create Firebase Project

Open:

[Firebase Console](https://console.firebase.google.com/?utm_source=chatgpt.com)

---

### 2. Add Flutter App

Register:

* Android App
* iOS App (optional)

---

### 3. Install FlutterFire CLI

Official Documentation:

[FlutterFire Documentation](https://firebase.flutter.dev/docs/overview?utm_source=chatgpt.com)

Install command:

```bash id="v73e0t"
dart pub global activate flutterfire_cli
```

---

### 4. Configure Firebase

```bash id="ov0ljn"
flutterfire configure
```

This generates:

```bash id="cw9k72"
firebase_options.dart
```

---

## 📦 Dependencies

Add dependencies in `pubspec.yaml`

```yaml id="n7jq9k"
dependencies:
  flutter:
    sdk: flutter
  firebase_core: latest_version
  firebase_auth: latest_version
  cloud_firestore: latest_version
  firebase_database: latest_version
```

---

## ▶️ Run Project

```bash id="qsvz5r"
flutter pub get
flutter run
```
